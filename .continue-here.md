## 🔑 Key Decisions Made

### Phase 2 Decisions
1. **Convenience functions approach**: Added `float_gte` and `float_lte` to avoid verbose `or` chains
2. **Selective migration**: Only migrated comparisons between float quantities, left exact comparisons (== 0) unchanged
3. **Comment discipline**: Added inline comments explaining tolerance usage at each migration site

### Phase 3 Decisions
1. **Global property over filter**: Chose `$formatFloat` global property pattern (consistent with existing `$numberFormat`, `$durationFromMillisec`)
2. **6-decimal standard**: Maintained backend precision standard (6 decimals) vs. existing local `roundQuantity` (4 decimals)
3. **Strip trailing zeros**: Default behavior to show "100" instead of "100.000000" for better UX
4. **2-decimal progress**: Progress percentages limited to 2 decimals (99.99%) for readability
