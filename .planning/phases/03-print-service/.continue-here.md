<decisions_made>

- Docker secret via bind-mounted file (not swarm secret) — keeps print service as standalone Compose, works without making print server a swarm node
- Token secret named `api_token` (target) so pydantic-settings `secrets_dir` finds it at `/run/secrets/api_token` matching field name `api_token`
- `context=api` + `consumer_type=3psw` combination uniquely identifies print service token; `verify_token` rejects api-context tokens, so print service token cannot use any other endpoint
- Fixed token `_key="print-service"` + `overwrite=True` for idempotent re-runs of db_init
- Token written to `/output/print_service_api_token` (config dir bind-mounted into init-db service); ansible `wait_for` on that file implicitly waits for init-db completion
- `expires_at=datetime(2099, 12, 31)` used instead of None since `TokenRecord.expires_at` is non-optional
- Token inserted only into PROGRESS_PROD (not DEV/TEST) — it's a production service credential
</decisions_made>
