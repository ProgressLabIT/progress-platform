**Module docstring** (at the top):
```python
"""
Float precision utilities for tolerance-based comparisons and rounding.

This module provides functions for comparing and rounding float values with
epsilon-based tolerance to avoid floating-point precision errors. The standard
tolerance (epsilon) is 1e-6, matching the 6-decimal precision standard used
throughout the system.

**Why tolerance-based comparisons:**
Floating-point arithmetic can produce values like 99.999999 when 100.0 is expected
due to division operations. Direct equality (==) would fail, but tolerance-based
comparison treats these as equal.

**Standard epsilon:** 1e-6 (absolute tolerance, not relative)

**Usage examples:**
```
from utils.float_precision import float_equals, round_float

# Comparison
if float_equals(calculated_qty, expected_qty):
    # Quantities match within tolerance
    pass

# Rounding for display or storage
clean_value = round_float(1/3)  # Returns 0.333333 (6 decimals)
```
"""
```

**Imports:**
```python
import math
from utils.config import get_config
```

**Implement 4 functions with full type hints and detailed docstrings:**

1. `float_equals(a: float, b: float, epsilon: float = 1e-6) -> bool`
   - Docstring: Description, params (a, b, epsilon), returns, usage example, edge cases (NaN handling per IEEE 754 - NaN != NaN)
   - Implementation: Return `math.isclose(a, b, abs_tol=epsilon, rel_tol=0.0)` after NaN check
   - NaN edge case: If either value is NaN, return False (except NaN == NaN also returns False per IEEE 754)

2. `float_less_than(a: float, b: float, epsilon: float = 1e-6) -> bool`
   - Docstring: Description, params, returns, usage example (quantity checks, progress thresholds)
   - Implementation: `a < b and not float_equals(a, b, epsilon)`
   - Handles edge case: 99.999999 < 100.0 with epsilon returns False (treated as equal)

3. `float_greater_than(a: float, b: float, epsilon: float = 1e-6) -> bool`
   - Docstring: Description, params, returns, usage example
   - Implementation: `a > b and not float_equals(a, b, epsilon)`

4. `round_float(value: float, decimals: int = None) -> float`
   - Docstring: Description, params (decimals=None means "use config value"), returns, usage example
   - Implementation:
     ```python
     if decimals is None:
         decimals = get_config().float_precision_decimals
     if math.isinf(value) or math.isnan(value):
         return value  # Return infinity/NaN as-is
     return round(value, decimals)
     ```

**Key requirements:**
- Full type annotations for all functions
- Detailed docstrings with description, params, returns, examples, edge cases
- NaN handling per IEEE 754 standard
- No bounds checking (accept any float Python supports)
- Absolute epsilon (always 1e-6), not scaled
- Infinity handling: return as-is in round_float (rounding infinity is undefined)

**Module organization:** Clean, focused utility module following codebase pattern of domain-specific utils (similar to dt.py, but with extensive documentation per user requirements).
