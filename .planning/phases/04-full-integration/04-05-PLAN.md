Output: PrintDialog.vue with chunked btoa conversion that handles PDFs of any size.

In `sendToPrinter()` function around line 742, replace:

```js
data = btoa(String.fromCharCode(...new Uint8Array(pdfBytes)));
```

With a chunked conversion that processes 8192 bytes at a time:

```js
const bytes = new Uint8Array(pdfBytes);
let binary = '';
const chunkSize = 8192;
for (let i = 0; i < bytes.length; i += chunkSize) {
  binary += String.fromCharCode.apply(null, bytes.subarray(i, i + chunkSize));
}
data = btoa(binary);
```

Key points:
- Uses `subarray` (not `slice`) for zero-copy view on the same buffer
- Uses `String.fromCharCode.apply(null, chunk)` which handles 8192 args safely (well under V8's limit)
- 8192 is a safe chunk size (V8 limit is ~65,000 arguments)
- Result is identical base64 string — only the conversion path changes

Do NOT refactor to use the `generatePdf()` export from `lib/print/index.js` — the inline code in PrintDialog handles gs1datamatrix migration and template cleaning that is specific to the dialog context. Keep changes minimal: only fix the btoa line.
