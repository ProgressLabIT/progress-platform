### File 1: MovementsRoot.vue

**Step 1: Update template display (Line 116)**

Replace the local roundQuantity calls with $formatFloat:

```vue
<!-- OLD: -->
{{ roundQuantity(props.row.qt_confirmed) }} / {{ roundQuantity(props.row.qt_planned) }}

<!-- NEW: -->
{{ $formatFloat(props.row.qt_confirmed) }} / {{ $formatFloat(props.row.qt_planned) }}
```

**Step 2: Remove local roundQuantity method (Lines 458-464)**

Delete the entire method:

```javascript
// DELETE THIS METHOD:
roundQuantity(value) {
  if (value === null || value === undefined) {
    return '-';
  }
  // Round to 4 decimal places to keep visualization stable
  return Math.round(value * 10 ** 4) / 10 ** 4;
},
```

**Reason for removal**: The global $formatFloat provides the same functionality but:
- Rounds to 6 decimals (consistent with backend standard) instead of 4
- Handles more edge cases (NaN, Infinity)
- Centralized maintenance
- Consistent across all components
