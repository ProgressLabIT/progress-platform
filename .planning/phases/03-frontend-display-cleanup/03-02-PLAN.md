**Purpose**: Prevent users from seeing confusing values like "99.999999 / 100" or "100.000001%" in production screens.

**Output**:
- 6 production components updated
- Quantities formatted with $formatFloat
- Progress percentages formatted to 2 decimals
- Consistent clean display across all production views
</objective>
