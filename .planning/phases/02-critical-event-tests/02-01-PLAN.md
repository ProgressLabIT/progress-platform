**Class `TestStepCompletedDirect`** — direct event instantiation tests (per D-01, D-02):

1. `test_happy_path_non_last_step` (STEP-01): Create graph with `num_steps=2`. Set `last_work_session_started` on Job to work_session key. Instantiate `StepCompletedEvent(info=dict(event_type="STEP_COMPLETED", primary=True, user_key=g["user"]["_key"], batch_key=g["batch"]["_key"], step_key=g["product"]["steps"][0]["_key"]))`. Call `event.save()`. Assert `db.collection("StepExecutionData").find({"batch_key": batch_key, "step_key": step_key, "canceled": None})` returns a record with `status == "done"`.

2. `test_last_step_triggers_batch_completed` (STEP-02): Create graph with `num_steps=1` (single step = last step). Set `last_work_session_started`. Save event. Use `assert_event_dispatched(db, "BATCH_COMPLETED")` from helpers to verify BatchCompletedEvent was recorded in Event collection. Do NOT assert BatchCompleted side effects (per D-06).

3. `test_form_data_stored` (STEP-03): Create graph. Create a CustomField document in DB: `db.collection("CustomField").insert({"_key": "cf-test", "name": "Weight", "type": "number"})`. Pass `form_data=[{"field_key": "cf-test", "value": "42.5"}]` in the event info dict. Save event. Assert the StepExecutionData record contains `form_data` with the field value.

4. `test_work_session_key_set` (STEP-04): Create graph with `num_steps=2`. Set `last_work_session_started`. Save step event. Assert `event.info.work_session_key == g["work_session"]["_key"]` (set by `pre_processing` -> `get_current_work_session`). Also assert StepExecutionData record has `work_session_key` matching.

5. `test_temp_step_data_overwritten` (STEP-05): Create graph with `num_steps=2`. Set `last_work_session_started`. First, insert a StepExecutionData record manually with `status=None` (temp data): `db.collection("StepExecutionData").insert({"_key": "temp-sxd", "batch_key": batch_key, "step_key": step_key, "job_key": job_key, "status": None, "canceled": None})`. Then save StepCompletedEvent for that step. Assert only ONE StepExecutionData record exists for that step (overwrite=True upsert replaced it) and it has `status == "done"`.

6. `test_missing_batch_raises_value_error` (STEP-06): Create a user only. Instantiate StepCompletedEvent with a non-existent `batch_key="nonexistent"`. Assert `pytest.raises(ValueError, match="not found")` wrapping `event.save()`.

**Class `TestStepCompletedAPI`** — HTTP API layer tests (per D-03, D-04):

7. `test_http_endpoint_success` (STEP-07, STEP-08): Create graph with `num_steps=1`. Set `last_work_session_started`.
