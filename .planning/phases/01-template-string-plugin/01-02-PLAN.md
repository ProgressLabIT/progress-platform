  <name>templateResolver.js</name>
  <files>webapps/main/src/lib/print/templateResolver.js, webapps/main/src/lib/print/templateResolver.test.js</files>
  <behavior>
    Token regex: `/\{\{\s*([\w:.]+)\s*\}\}/g` matches `{{token}}` where token contains word chars, colons, dots.

    slugify(name: string) -> string:
    - Lowercase the entire string
    - Remove parenthesized content (including parens): `\([^)]*\)` → ''
    - Replace non-alphanumeric runs with single underscore: `[^a-z0-9]+` → '_'
    - Collapse consecutive underscores: `_+` → '_'
    - Trim leading and trailing underscores
    - Examples: 'Product Color' → 'product_color', 'Qty (pcs)' → 'qty'

    encodeExpression(expr: string, customFields: CustomField[]) -> string:
    - Build slug→_key map from customFields: `Object.fromEntries(customFields.map(cf => [slugify(cf.name), cf._key]))`
    - Replace each `{{token}}`:
      - If token starts with 'cf::': look up slug in map, return `{{cf::_key}}` if found, else pass through unchanged
      - Otherwise: return token unchanged (preset passthrough)
    - If expr is null/undefined, return '' (safe guard)

    decodeExpression(expr: string, customFields: CustomField[]) -> string:
    - Build _key→slug map from customFields: `Object.fromEntries(customFields.map(cf => [cf._key, slugify(cf.name)]))`
    - Replace each `{{token}}`:
      - If token starts with 'cf::': look up _key in map, return `{{cf::slug}}` if found, else pass through unchanged
      - Otherwise: return token unchanged (preset passthrough)

    resolveExpression(expr: string, context: TemplateContext, customFields: CustomField[]) -> string:
    - Build _key→field map (not strictly needed but enables future extension)
    - Replace each `{{token}}`:
      - If token starts with 'cf::': extract key after 'cf::', call `context.getCustomFieldValue(key)`, return `String(value ?? '')`
      - Otherwise: call `context.getPresetValue(token)`, return `String(value ?? '')`
    - Handle null/undefined expr: return ''

    Keep module under ~80 lines (per research guidance — this is intentionally simple regex transforms).
  </behavior>

    - File should be pure ES module with no framework dependencies

  </implementation>
</feature>
